# OCR language data

These `eng`, `jpn`, and `kor` traineddata files were cached by Tesseract.js 7.0.0 during local OCR verification and are included so image OCR does not need a first-run language-data download. Tesseract.js obtains its default language files from `@tesseract.js-data/*/4.0.0_best_int` on jsDelivr. The files are used locally with `langPath`, `gzip: false`, and `cacheMethod: 'none'`.

Tesseract language data is distributed under Apache-2.0; see [LICENSE.md](LICENSE.md) and the [upstream model repository](https://github.com/tesseract-ocr/tessdata_best).
